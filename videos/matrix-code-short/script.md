# The Matrix code = sushi recipes: Thai script (FINAL, user-locked 2026-10-29)

1. ฮุก
รู้มั้ยว่า รหัสลับใน The Matrix คือสูตรการทำซูชิ

2. บริบท
ในหนัง The Matrix ปี 1999 มีรหัสสีเขียวไหลลงมาบนหน้าจอ กลายเป็นภาพจำของโลกจำลองสุดลึกลับ หลายคนคิดว่ามันเป็นรหัสคอมพิวเตอร์ที่ซับซ้อน

3. แต่
แต่เบื้องหลังตัวอักษรเหล่านี้กลับมีที่มาที่คาดไม่ถึง เพราะมันเกี่ยวข้องกับหนังสือทำอาหารญี่ปุ่น!

4. เฉลย
Simon Whiteley คนออกแบบหนัง สแกนตัวอักษรญี่ปุ่นจากหนังสือทำอาหารของภรรยาเขา แล้วนำมาสลับ กลับด้าน และทำให้ไหลลงมาเหมือนสายฝน

Source: Whiteley, CNET 2017 (his own account; some outlets doubt the recipe claim).
