# Halloween (1978): Michael Myers mask = Captain Kirk mask: Thai script (FINAL, user-locked 2026-10-29, replaces the 6-paragraph version)

1. ฮุก
รู้มั้ย หน้ากากฆาตกรที่น่ากลัวที่สุดในหนัง Halloween จริงๆ แล้วทำมาจากสิ่งนี้

2. บริบท
หนัง Halloween ปี 1978 เป็นเรื่องของฆาตกรใส่หน้ากากสีขาว ที่ไล่ฆ่าคนในคืนวันฮาโลวีน หนังมีงบน้อยมาก ทีมงานเลยไม่มีเงินสร้างหน้ากากใหม่ ต้องหาหน้ากากราคาถูกในร้านชุดแฟนซีแทน

3. แต่
แต่หน้ากากที่เขาเลือก กลับเป็นหน้าของพระเอกหนังอวกาศ!

4. เฉลย
มันคือหน้ากากราคาถูกของกัปตันเคิร์กจาก Star Trek ที่ทีมงานดึงคิ้วออก พ่นสีหน้าให้ขาวซีด และขยายรูตาให้กว้างขึ้น
