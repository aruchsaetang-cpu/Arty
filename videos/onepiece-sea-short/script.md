# One Piece live action: sea light trick: Thai script (FINAL, user-locked 2026-10-29)

1. ฮุก
รู้มั้ยว่าในหนัง one piece live action ฉากนี้ ไม่ได้ใช้ CGI และถ่ายด้วยเทคนิคที่คุณอาจจะคาดไม่ถึง!

2. บริบท
ทีมงานต้องถ่ายฉากโจรสลัดบนเรือขนาดเท่าของจริงในสตูดิโอ พวกเขาเลยต้องหาวิธีทำให้ทะเลดูสมจริง แม้จะไม่มีทะเลอยู่ตรงหน้าก็ตาม

3. แต่
แต่เทคนิคที่ใช้กลับง่ายกว่าที่คิด!

4. เฉลย
พวกเขาใช้กระดาษสีชิ้นเล็ก ๆ ร่วมกับลม เพื่อทำให้แสงและเงาเคลื่อนไหว คล้ายกับแสงสะท้อนบนผิวน้ำที่กำลังไหวอยู่ตลอดเวลา!
