# MakeHuman base assets (CC0)

Vendored from https://github.com/makehumancommunity/makehuman (`makehuman/data`):
`base.obj`, `default.mhskel`, `default_weights.mhw` and six macro targets in `targets/`.

These assets were explicitly released as **CC0** in September 2020 by Data Collection AB,
Joel Palmius and Jonas Hauquier (see the header of each file). Used by `lookdev/character_mh.py`.
