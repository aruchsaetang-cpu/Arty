## 2. จังหวะการตัด (Pacing)

นับช็อตด้วยตาจาก contact sheet 4 fps แล้วเทียบกับ scene detection ของ FFmpeg (`select='gt(scene,0.35)'`)

| คลิป | ยาว | จำนวนช็อต | เฉลี่ย/ช็อต |
|------|-----|----------|------------|
| c1 | 7.7 s | 5 | 1.5 s |
| c2 | 9.5 s | 6 | 1.6 s |
| c3 | 5.5 s | 6 | 0.9 s |
| c4 | 5.9 s | 5 | 1.2 s |
| c5 | 6.3 s | 3 | 2.1 s |
| c6 | 10.0 s | 6 | 1.7 s |
| **รวม** | **44.9 s** | **31** | **≈1.45 s** |

- ช็อตสั้นสุดประมาณ 0.5 s (ไฟเปลี่ยนเป็นขั้นๆ ตอนตัวเลขนับใน c3) ยาวสุดประมาณ 3 s (กล้อง dolly ผ่านรั้วใน c5)
- **กล้องไม่เคยนิ่ง** ทุกช็อตมี push-in, pull-back, orbit หรือ dolly ตลอดเวลา
  scene detection จึงเจอ "จุดตัด" เป็นกลุ่มหลายเฟรมติดกัน (เช่น c3: 1.17–1.27 s, c6: 5.08–5.28 s) ซึ่งเป็น whip หรือ motion blur ไม่ใช่การตัดแข็ง
- การตัดตรงกับรอยต่อของวลีหรือซับเกือบทุกครั้ง: ภาพเปลี่ยนพร้อมซับก้อนใหม่
- 3 วินาทีแรก: ตัดถี่พอๆ กับช่วงกลาง (1–2 ครั้ง) แต่ "ภาพแรกเป็นภาพแรง" เสมอ เช่น หน้าคน extreme close-up, สะเก็ดไฟเจียร หรือกล้องซูมเข้าไปในเส้นผม
  ช่วงท้ายของคลิปที่อัดมาไม่มีให้ดู เลยเทียบไม่ได้
- ตัดคำพูดแบบไม่มีช่องว่าง: silencedetect (−35 dB, 0.15 s) **ไม่เจอช่วงเงียบเลย**ในช่วงที่มีเสียงพูด
  ช่วงเงียบ 0.36–1.04 s ที่ต้นไฟล์คือช่วงที่ YouTube ยังโหลด ไม่ใช่ส่วนของคลิป
  เสียงหายใจถูกตัดออก ช่องว่างระหว่างประโยคเหลือน้อยกว่า 0.15 s และมีดนตรีรองพื้นต่อเนื่องตลอด
- ความเร็วพูดประมาณ **3 คำ/วินาที (≈180 wpm)** เช่น c2 มี 29 คำใน 9.5 s

## 3. ซับไตเติล

ตัวอย่างข้อความที่ถอดได้ (ซับ = คำพูดทุกคำ)
- c1–c2: "If you leaned / forward / and blasted / through a race / Naruto style / could you actually / run faster? / Well / leaning forward / would mean / the air is hitting less / of your body / which could / make you / a tad quicker / But without / swinging your arms / you can't really / increase your pace"
- c3: "a light bulb / that lasted / 2,000 hours / But there was a / problem / The longer …"
- c4: "He cut open / a giant tank / dumped her body / inside / and welded / it shut"
- c5: "The dog / kept clawing / at the same spot / beside / the sidewalk / while his owner / watched from / the front door"
- c6: "If every strand / of your hair / moved on its own / it could / braid itself / or even carry / small items / But every hair / would need / to be around / seven times wider"

| คุณสมบัติ | ค่าที่วัดได้ |
|----------|-------------|
| จำนวนคำต่อก้อน | 1–5 คำ เฉลี่ย **≈2.2 คำ** ส่วนมาก 2–3 คำ |
| เวลาที่ก้อนหนึ่งอยู่บนจอ | 0.5–1.75 s เฉลี่ยประมาณ 0.85 s |
| จำนวนบรรทัด | **1 บรรทัดเสมอ** ยาวสุดประมาณ 23 ตัวอักษร (กว้างประมาณ 90% ของจอ) |
| ตำแหน่ง | กึ่งกลางแนวนอน จุดกลางตัวอักษรอยู่ที่ **≈78% ของความสูง** (y≈1500 จาก 1920) เหนือโซน UI ของแพลตฟอร์ม |
| ขนาด | ตัวอักษรสูงประมาณ 3.3% ของความสูงภาพ เทียบได้กับฟอนต์ประมาณ 80–84 px ที่ 1920 |
| ฟอนต์ | sans-serif หนามาก ทรง geometric (ใกล้เคียง Montserrat ExtraBold) สีขาว |
| ขอบ/เงา | ขอบเข้มบางประมาณ 3 px และเงาตกนุ่มด้านล่าง ไม่มีกล่องรองพื้น |
| ตัวพิมพ์ | พิมพ์ตามที่พูด ตัดจุดและจุลภาคท้ายออก แต่เก็บ "?" ไว้ ตัวเลขเขียนแบบ "2,000" |
| การเน้นคำ | **ไม่มี** ทุกคำสีเดียวกันและขนาดเดียวกัน คำสำคัญไปเน้นด้วยกราฟิกในฉากแทน (ข้อ 4) |
| การปรากฏ | **โผล่ทันทีแล้วสลับแบบตัดแข็ง** ไม่มีเด้ง ไม่เฟด ไม่พิมพ์ทีละตัว |
| แบ่งก้อนตรงไหน | ตามวลีที่พูด: ขึ้นก้อนใหม่ก่อน and/but/which/while และหลังเครื่องหมายวรรคตอน ไม่ทิ้ง "the/of/your" ค้างไว้ท้ายก้อน |

## 4. กราฟิกและเอฟเฟกต์

- **ตัวเลขเป็นวัตถุในฉาก**: ป้ายตัวเลขพลิกสีเข้ม "2000 / HOURS" ที่นับขึ้นจาก 0 อยู่ราวๆ ส่วนบนหนึ่งในสามของจอ (c3)
  หรือคำเรืองแสงสีฟ้า "2 Times → 3 Times → 5 Times" ที่เปลี่ยนเป็นขั้นตามคำพูด (c6)
- **ไฮไลต์วัตถุด้วยสีเหลืองเรือง** เช่น ถุงศพ (c4) หรือเส้นผม (c6) เพื่อชี้สิ่งที่กำลังพูดถึง
- **เส้นความเร็วแบบอนิเมะ** แผ่ออกจากกลางจอและกระพริบสลับ พร้อมสัญลักษณ์ "!?" ใช้ตอนคำถามหรือตอนเร่งความเร็ว (c1 "run faster?", c2 "a tad quicker")
- **ภาพแสดงสิ่งที่มองไม่เห็น**: ลมเป็นเส้นสีเขียวหรือแดง (c2) และการเปลี่ยนแสงตามเวลาแบบ time-lapse (c3)
- สี: พื้นหลังสตูดิโอฟ้าไซแอนอิ่มตัว ไล่จาก #0AA0E0 ไป #7FE0FF (c1, c2, c6) หรือฉากสมจริงโทนอุ่นเหลืองและโทนฟ้ากลางคืน คอนทราสต์สูง
- โลโก้ "ZACK D FILMS" อยู่บนเสื้อและของในฉาก (product placement ของแบรนด์ตัวเอง) ไม่มีลายน้ำมุมจอ
- ภาพทั้งหมดเป็น 3D render (ตัวละครสไตล์ Unreal หรือ Blender)
  **สกิลนี้สร้างภาพ 3D เองไม่ได้** สิ่งที่ทำได้คือตัด จัดจังหวะ ใส่ซับ ใส่กราฟิกซ้อน และเคลื่อนกล้องแบบ 2D บนฟุตเทจที่ผู้ใช้ให้มา

## 6. การเล่าเรื่อง

- **ฮุคประโยคแรก**ใช้ 1 ใน 3 แบบนี้
  1. สมมติ: "If you…", "If every strand of your hair…", "What if…"
  2. เล่าเหตุการณ์ที่น่าตกใจทันที: "He cut open a giant tank…"
  3. สิ่งผิดปกติที่ชวนสงสัย: "The dog kept clawing at the same spot…"
- พูดกับคนดูตรงๆ ("you", "your") ใช้ประโยคสั้น ไม่มีอินโทรและไม่ทักทาย คำแรกคือเนื้อเรื่อง
- โครงเรื่อง: ฮุค/คำถาม → แสดงภาพให้เห็นว่าเกิดอะไรขึ้น → **"But…" / "Well…" หักมุม** → ผลลัพธ์หรือคำตอบ
- ทุกประโยคมีภาพที่ "แสดงตามคำพูด" แบบตรงตัว (พูดว่า "2,000 hours" ก็มีตัวเลข 2000 ขึ้นมา)
- ชื่อคลิปเป็นประโยคคำถามหรือพาดหัว + อีโมจิ 1 ตัว เช่น "Dog Uncovers A Hidden Gas Leak 😨"
