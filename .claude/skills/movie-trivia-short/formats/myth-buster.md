# Format D: "คนเข้าใจผิด" (myth-buster) — idea from the user's 2026-10-23 reference

Reference: an English Short about "Spider-Verse DID use AI, but not the way you think" (two iPad recordings,
12.4 s + 10.3 s). Measured from the frames:

| Item | Reference |
| --- | --- |
| Layout | Split screen: B-roll on the top half, the presenter's talking head on the bottom half; sometimes the presenter goes full screen for the key word ("is completely WRONG.") and the B-roll goes full screen for the punchline |
| Hook card | A headline in white on a dark box across the split line for the first ~2.5 s |
| Captions | 1–3 words, white with a black outline, on the split line |
| Graphics | Logo cards (Sony Pictures Imageworks) and a yellow comic-style label ("PREDICTIONS FROM MACHINE LEARNING") on the B-roll |
| Story | A popular belief → "is completely wrong" → what really happened, step by step |

How it fits the channel: keep the **blur layout (main style)**. The myth-buster idea fits ฮุก → บริบท → แต่ → เฉลย
directly: ฮุก = the belief, บริบท = why people believe it, แต่ = "แต่ความจริงคือ…", เฉลย = what really happened.
If the user records their face, use the presenter circle in the blur layout (`--facecam`). Use a yellow
label or a logo card only as an extra, the way arrows are used.
